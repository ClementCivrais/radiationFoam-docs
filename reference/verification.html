Verification Record

The present page records the verification of radiationFoam as it is written in the repository: the commit messages and the specifications in docs/. Every result below is quoted from the commit given in the first column (short hash of the radiationFoam repository, git show <hash>). The code was developed in the DSMC_Rovibronic repository and moved here with its history on 2026-11-16 (commit 83fd476); the dated reports named in the commit messages (run/RAD/...) are kept in that repository.

Verification means comparison with an analytic result, an independent transcription of the same formulas, or another code solving the same equations. Comparisons with experiment (EAST) are listed separately at the end.

How the verification was organised

The library was first written as a transcription of the radiation module of the PICLas code, and every routine was checked against PICLas reference outputs, to round-off where the same constants were used (phases 1a-2e, 2026-11-14). On 2026-11-14 the replica options were removed by user decision and only the corrected physics was kept (commit 9ea3d42; docs/RADIATION_RESTRUCTURE.md section 6). From then on, every change has been gated by md5 identity of the regression outputs, the instrument test suite and independent Python references. PICLas appears below only as the past verification reference.

Phase 1a. Atomic lines (atomicLines, Voigt line shape) and the singleCell mode, against the PICLas single-cell N and O references: maximum relative error 4.5e-6 (tolerance 1e-5); the residual is the SI-2019 constants.

99d6fea

RADIATION_SPEC.md written (the equations with file and line references, the regression-case conditions, a list of inconsistencies), with an independent Python baseline of the atomic path that reproduces the single-cell references to 2e-10.

33ec715

Phase 1b. The population models boltzmannTemperatures and cellDistribution: single-cell N and O bit-identical after the refactoring, the distribution test exact. Referenced atomic database (NIST ASD v5.12, Johnston 2006 Stark widths).

be594a5

Library review. Atomic level cut also without electrons: with \(n_e=0\) the autoionising levels above the ionisation limit were in the partition function and populated (O I 0.9 % and 4.7 % of the atoms at 20 and 25 kK); after the fix the populations agree with a Boltzmann distribution over the bound levels to 1e-14, in both boltzmannTemperatures and cellDistribution boltzmannFill. A distribution g list of the wrong length is now fatal (it was dropped silently).

3153f7a

Library review, round 2 (R3): natural, phase and resonance widths of the atomic lines from their sources (natural and resonance widths as written by Laux 1993, Eqs. 4.19-4.20; phase width from impact theory). Open item 1 of the continuum (Johnston nitrogen slab) settled: no defect.
