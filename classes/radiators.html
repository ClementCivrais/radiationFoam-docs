Radiating species

Source: src/radiation/radiators/.

A radiating species computes the spectral emission \(j_\lambda\) [W m-3 sr-1 m-1] and absorption \(\kappa_\lambda\) [m-1] of one species in one cell. The base class is run-time selected; two derived classes exist:

radiators/
    basic/radiatingSpecies/     abstract base, selector (entry model)
    derived/atomicLines/        atoms and atomic ions, line by line
    derived/diatomicBands/      diatomic molecules and ions, band systems
                                line by line (three source files)

Theory: Atomic bound-bound lines, Diatomic band systems, line by line.

radiatingSpecies (base class)

src/radiation/radiators/basic/radiatingSpecies/radiatingSpecies{,New}.{H,C}

One sub-dictionary per species in the species dictionary of system/radiationProperties, keyed by the species name. The selector reads model.

Keyword

Type

Default

Meaning

word

particle mass [kg]

radius

scalar

required

hard-sphere radius [m] (phase broadening of atomic lines; unused by diatomicBands)

<model>Coeffs

dictionary

required

coefficients of the derived class

The entries windowEdge and subBinLines were removed: a case that gives either (in the species dictionary or an enclosing one) stops with a FatalIOError. The line placement has one form: every grid point receives the line profile integral over its own bin, at the window edges and for lines narrower than a bin (Line shapes and broadening).

Interface:

  • name(), mass(), radius();

  • levels(): the radiationLevels whose populations the species needs (Common data classes);

  • addEmissionAbsorption(grid, populations, state, speciesi, emission, absorption): add the species’ \(j_\lambda\) and \(\kappa_\lambda\) on the grid, with the populations of the radiationPopulationModel (Population models); speciesi is the index of the species in the cell state.

The species does not compute populations; it passes its levels to the population model and receives \(n_i\), the bound limit and the electron temperature for the Stark width.

atomicLines

src/radiation/radiators/derived/atomicLines/atomicLines.{H,C}

Bound-bound emission and absorption of an atom or atomic ion from a list of levels and lines in the atomic format of the database (Database files and generators). At construction it reads the transition file and prints the number of levels and lines.

The entry starkDensity was removed (electron-impact Stark broadening with \(n_e\) and \(T_e\) of the cell is the only form); a case that gives it stops with a FatalIOError.

N
{
    model           atomicLines;
    mass            2.326e-26;      // [kg]
    radius          0.7e-10;        // [m]

    atomicLinesCoeffs
    {
        transitionFile      "$RADIATIONFOAM_DIR/src/radiation/database/atoms/N_I.dat";
        ionisationEnergy    117225.7;       // [cm^-1], NIST ASD v5.12
        starkExponent       0.33;           // Johnston (2006) Eq. 3.13
        lineShape           voigtWhitingOliveroLongbothum;
    }
}

Per cell (addEmissionAbsorption):

  1. skip the species if \(n < 10\) m-3 or \(T_{\mathrm{trans}} < 10\) K, or if the population model returns no population;

  2. compute the decay rate \(\Gamma\) of each level, the mixture density and the collision rate for the phase width (radiating species only);

  3. per line: skip if the upper level is above the bound limit; compute the integrated emission and absorption and the five Lorentzian widths and the Doppler width; skip if farther than \(100\max(w_L, w_D) + \Delta\lambda\) from the grid; get the bin-integrated profile from the line-shape model and add \(\max(0,\epsilon)\phi_i\) to the emission and \(k\,\phi_i\) (signed, gain kept) to the absorption;

  4. with a population model that models levels (cellDistribution boltzmannFill), report the emission of the lines with a modelled upper level (recordModelledEmission).

Members: nLevels(), nLines(), levels(). Constants: exact SI 2019 \(k_B, h, c, e\).

diatomicBands

src/radiation/radiators/derived/diatomicBands/: diatomicBands.H, diatomicBands.C (constructor, per-cell coefficients), diatomicBandsRead.C (molecule file), diatomicBandsLines.C (line positions, Hoenl-London factors, levels).

Bound-bound emission and absorption of a diatomic molecule or diatomic ion from the band systems of a molecule file of the database (Database files and generators). Every [band-...] block of the file is computed; there is no band selection.

Keyword (diatomicBandsCoeffs)

Type

Default

Meaning

transitionFile

fileName

required

molecule file (environment variables expanded)

 
N2
{
    model           diatomicBands;
    mass            4.652e-26;      // [kg]
    radius          0;              // unused by this class

    diatomicBandsCoeffs
    {
        transitionFile  "$RADIATIONFOAM_DIR/src/radiation/database/molecules/N2.dat";
    }
}

Construction (once):

  • readParade reads the states, bands, 17 constants per state and the transition rows (records starting with c are comments; exactly one record is skipped after each row count, item 1 of the header); it converts energies from cm-1 to J and \(r_e\) from cm to m;

  • the log lists every band (upper and lower state, type, rows, rows not read);

  • buildLines builds, per row \((v', v'')\), the band origin, the band strength \(c_S\) and every rotational line of the transition type (1 to 6; another type is a fatal error): wavenumber, emission factor per unit \(n_u/g_u\), absorption factor per unit \(n_l/g_l - n_u/g_u\), rotational term difference \(F' - F''\), and the indices of its upper and lower level; it creates the levels (key, \(g\), energy parts) and copies the state constants into the radiationLevels;

  • the log gives the number of vibrational transitions, lines and levels.

Fatal errors at construction: a band referring to a state outside [Energy-Levels], a type-3 band with altnat' \(\neq 0\), a type 4-6 band with \(k_{\max} > 500\), the two states of a type 3/5/6 band with different spins, a spin \(S > 1\) in the matrix method, a level reached with two different energies, a level outside the key range.

Per cell (addEmissionAbsorption):

  1. skip if \(n < 10\) m-3 or \(T_{\mathrm{trans}} < 10\) K, or if the population model returns no population;

  2. compute the foreign-gas density and molar mass;

  3. per vibrational transition: skip if outside the window (origin test); compute the Doppler, self, foreign, natural and Stark widths at the band origin, the Voigt width and the 2001-point cumulative Whiting table over \(\pm 25\) Voigt widths;

  4. per line: \(\epsilon = ` emission factor :math:\)times n_u/g_u`; decide whether it is placed (emissionSelectsLines of the population model, threshold \(10^{-25}\) in the code’s units); get \(n_l/g_l\) from lineLowerPopulation; place the bin integrals of the cumulative profile on the grid; add \(\epsilon/10^{10}\,\phi_i\) and \(k/10^{10}\,\phi_i\) (signed);

  5. as atomicLines, report modelled-level emission when the population model models levels.

Members: nLines(), levels(). Constants: exact SI 2019 \(k_B, h, c\), CODATA 2018 atomic mass unit, \(e a_0 = 2.5415785\times10^{-18}\) esu cm.

The header diatomicBands.H lists, as items 1-13, the forms of the verified version that are kept on purpose (reader, \(k_{\max}\), type-specific terms, widths); they are summarised in Diatomic band systems, line by line.
