Instrument classes

Source: src/radiation/instrument/.

instrument/
    instrumentFunctions/
        basic/instrumentFunction/        abstract kernel, discrete convolution
        derived/instrumentGaussian/      gaussian
        derived/instrumentVoigt/         voigt
        derived/instrumentTopHat/        topHat
        derived/instrumentTrapezoid/     trapezoid
        derived/instrumentTabulated/     tabulated
        derived/instrumentComposite/     composite
        derived/instrumentEastLineShape/ eastLineShape
    shockTubeInstrument/                 measurement model of one camera

The physics of every class (kernel formulas, discrete convolution, shock front criteria, units) is in Instrument model: reproducing a shock-tube measurement. This page lists the run-time names and the dictionary keywords as the code reads them. The instrument is used by the shockTube1D transport mode (Transport classes) and by the test application Test-radiationInstrument.

instrumentFunction (base class)

Files: instrumentFunctions/basic/instrumentFunction/instrumentFunction.{H,C}, instrumentFunctionNew.C.

Abstract base of every instrument response function: a normalised kernel \(K(s)\) [1/length] of the offset \(s\), used for the spectral instrument line shape (ILS, spectralResponse) and the spatial resolution function (SRF, spatialResponse). It is selected by run-time selection on the type entry of its dictionary.

Keywords common to every type

Keyword

Type

Default

Meaning

type

word

(required)

Run-time name of the derived class (below).

lengthUnit

word

m

Unit of every width of the dictionary: m, cm, mm, um, nm. Stored lengths are always SI.

conserveAtEdges

bool

true

Renormalise each kernel to the part inside the window, so the trapezoid integral is conserved; false loses the content scattered beyond the window edges.

convolution

word

auto

Sum over the sources on a uniform grid: direct, fft (linear convolution by FFT, same weights and normalisation, round-off differences only) or auto (FFT when the kernel stencil is wider than the grid, \(2M+1 > N\), and \(N \ge 4096\): a kernel that spans the window, as the EAST line shape over the detector).

Main member functions:

  • cdf(s), pdf(s): \(C(s)\) and \(K(s)\); by default those of the piecewise-linear table set by setTable(nodes, density) (exact CDF of the linear density, normalised to unit area);

  • support(): half range beyond which \(K = 0\) [m];

  • width(): characteristic full width [m] (pure virtual);

  • convolve(y, f): bin-averaged discrete convolution on an increasing, possibly non-uniform grid (virtual, so a derived class can replace it);

  • trapezoid(y, f) (static): the trapezoid integral that convolve conserves.

The removed type piclasInstrBroadening stops with a FatalIOError that points to trapezoid.

gaussian

Class instrumentGaussian. Gaussian of given FWHM (or standard deviation), analytic CDF.

Keyword

voigt

Class instrumentVoigt. Voigt from the FWHM of its Gaussian and Lorentzian parts, either tabulated exactly or as the pseudo-Voigt of Thompson, Cox and Hastings (1987).

Keyword

Type

Default

Meaning

scalar

(required)

fwhmLorentz

scalar

(required)

topHat

Class instrumentTopHat. Centred top hat (square wave) of full width \(w\); the camera gate smear \(d_\mathrm{gate} = U_s t_\mathrm{gate}\).

Keyword

Type

Default

Meaning

width

scalar

(required unless the pair below)

Full width [lengthUnit].

shockSpeed

scalar

(with gateTime)

Shock speed \(U_s\) [m/s], always SI.

gateTime

scalar

(with shockSpeed)

Gate (exposure) time [s], always SI; \(w = U_s t_\mathrm{gate}\).

trapezoid

Class instrumentTrapezoid. Symmetric trapezoid of bottom width \(b\) and top width \(t\), unit area (height \(2/(b+t)\)); \(t = 0\) is the triangle of the EAST optics (Brandis and Cruden 2017, Eq. D1), \(t > 0\) the trapezoid of Eq. D3. The density is linear on the nodes \(-b/2, -t/2, t/2, b/2\), so the table CDF is exact. \(t = b\) gives a top hat.

Keyword

Type

Default

Meaning

baseWidth

scalar

(required)

Bottom width \(b > 0\) [lengthUnit].

topWidth

scalar

0

Top width \(0 \le t \le b\) [lengthUnit].

width() returns \(b\).

tabulated

Class instrumentTabulated. Kernel read from a two-column ASCII file (offset in lengthUnit, response of any scale; # lines are comments; offsets increasing, responses \(\ge 0\)), e.g. a measured ILS. Linear between the nodes, normalised to unit area over the file range.

Keyword

Type

Default

Meaning

file

fileName

(required)

Path of the table, expanded with fileName::expand (environment variables, OpenFOAM tags such as <constant>).

centre

scalar

0

Offset subtracted from the file offsets [lengthUnit] (e.g. the line position when the file gives absolute wavelengths).

centreFirstMoment

bool

false

Put the centroid of the linear density at zero instead.

width() returns the FWHM of the linear density (outermost half-maximum crossings).

composite

Class instrumentComposite. Convolution of several instrument functions, e.g. the EAST SRF \(f_\mathrm{opt}\otimes f_\mathrm{cam}\otimes f_\mathrm{motion}\), tabulated once at start-up on a uniform grid.

Keyword

Type

Default

Meaning

functions

dict

(required)

One sub-dictionary per component (any type, composite included); a component inherits lengthUnit from the composite unless it sets its own. Non-dictionary entries are ignored; at least one is needed.

resolution

scalar

200

    type        composite;
    lengthUnit  cm;
    functions
    {
        optics  { type trapezoid; baseWidth 0.041; topWidth 0; }
        camera  { type eastLineShape; form sqrtVoigt;

        motion  { type topHat; width 0.514; }
    }
}

eastLineShape

Class instrumentEastLineShape. The two empirical EAST line shapes of Brandis and Cruden (2017, Sec. IV.A, App. C), parameterised by the half widths at half maximum of their tables.

Keyword

Type

Default

Meaning

form

word

(required)

sqrtVoigt (ILS1) or gaussLorentz (ILS2).

halfWidthGauss

scalar

(required)

Gaussian HWHM \(w_G \ge 0\) [lengthUnit].

halfWidthLorentz

scalar

(required)

Lorentzian HWHM \(w_L \ge 0\) [lengthUnit]; not both zero.

ratio

scalar

0

\(a \in [0, 1]\), weight of the Lorentzian (gaussLorentz only).

cutoff

scalar

(required)

Half range \(R\) [lengthUnit] of the normalisation (sqrt-Voigt) or of the truncation (Gauss + Lorentz). The EAST database gives the width of the camera range (with windowMargin 0): the line shape spans the detector and is normalised over it (conserveAtEdges).

resolution

scalar

100

Table nodes per Voigt FWHM (sqrtVoigt only).

shockTubeInstrument

Files: shockTubeInstrument/shockTubeInstrument.{H,C}. Not run-time selected: one object per camera, constructed from the camera dictionary. It turns a radiance field \(I(x,\lambda)\) [W m-2 sr-1 m-1] into what the instrument reports.

low

instrument
{
    UVVis
    {
        window          UVVis;
        spectralResponse
        {
            type eastLineShape; lengthUnit nm; form sqrtVoigt;
            halfWidthGauss 0.28; halfWidthLorentz 0.070; cutoff 174.3;
        }
        bands           { UVVis_EAST (328 477); }
        shockFront      { criterion peakRadiance; band UVVis_EAST; }
        distanceUnit    cm;
        metricHalfWidth 2;
        spectra
        {
            nonequilibrium  { at peak; }
            equilibrium     { average (3 4.5); }
        }
    }
}

Test-radiationInstrument

Files: applications/test/radiationInstrument/Test-radiationInstrument.C. A verification driver of instrumentFunction and shockTubeInstrument. It reads the dictionary given by -dict (default system/instrumentTests); each sub-dictionary is one test, run in order, selected by kind:

kind

Entries

Output

convolve

function {...}, input (two columns: y [m], f), output

Two comment lines with the trapezoid integrals of f and g and their relative change, then y,f,g.

kernel

function {...}, nodes (min max n) [m], output

s,pdf,cdf.

band

input (lambda [m], I), bands { name (min max); } [nm], output

band,lambdaMin,lambdaMax,integral (integral in the unit of I \(\times\) m).

front

input (x [m], f), output

criterion,x0 for peakRadiance, maxGradient (on \(|{\rm d}f/{\rm d}x|\)) and riseFraction (0.5, upstream low, end values).

measure

instrument {...} (a shockTubeInstrument), input (line 1: nx nl; then nl wavelengths [m], nx positions [m], nx·nl values, row-major in x), output, bandOutput

The measured field in the input format, and x plus one column per band; the front of the configured criterion on band 0 is printed in the log.

Note that the front kind calls maxGradientLocation with direction 0 (the largest \(|{\rm d}f/{\rm d}x|\)), whereas shockTube1D uses the signed slope of the configured upstreamSide.
