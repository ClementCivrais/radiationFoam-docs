Profile classes

Source: src/radiation/profiles/shockTubeProfile/.

shockTubeProfile

shockTubeProfile reads the cell states of a 1-D shock-tube profile for the shockTube1D transport mode (Transport classes): per cell, the position \(x\) along the tube, the number density and the translational, rotational, vibrational and electronic temperatures of every radiating species, and the electron density and temperature. All quantities are SI (m, m-3, K). After reading, the cells are sorted by increasing \(x\); this order defines the cell index \(k\) of the outputs. Negative values read from either source are set to 0.

It is not a run-time selectable class: shockTube1D constructs it from the profile sub-dictionary of shockTube1DCoeffs, the names of the radiating species and the Time of the radiation case. The entry source chooses the reader.

Source macroFile

A comma-separated text file, one row per cell. Lines starting with # and empty lines are comments; the first other line is the header. Columns are found by name, in any order:

# synthetic post-shock profile (x [m]; n [m^-3], T [K])
x,n_e,T_e,n_N2,Ttrans_N2,Telec_N2,Trot_N2,Tvib_N2,n_N,Ttrans_N,Telec_N
-0.00345,1e+21,10000.0,2.56e+21,300.0,300.0,300.0,300.0,1e+15,300.0,300.0
...

A column given twice, a row with a different number of values than the header, a missing required column or a file without rows stops with a fatal error. Trailing blanks and carriage returns are stripped. The columns are the five per-species scalars of a multi-temperature state (density, \(T_{vib}\), \(T_{rot}\), \(T_{el}\), \(T_{trans}\)).

Source dsmcCase

The cell centres and fields of one time directory of a reconstructed dsmcFoam case are read directly (the mesh of the DSMC case is loaded without its controlDict, function objects or libraries). The DSMC function object dsmcVolFields (one instance per species, fieldName = the species name) writes, per species \(s\),

  • rhoN_<s>: number density [m-3];

  • translationalT_<s>: translational temperature [K];

  • internalT_<s>: the internal temperature [K], i.e. the one temperature whose Boltzmann distribution over the rovibronic \((n, v, J)\) ladder of the species has the sampled mean internal energy.

dsmcFoam writes no separate rotational, vibrational or electronic temperature, because its internal state is rovibronic. The default mapping is therefore

    case        "../dsmcCase";
    time        latestTime;
    direction   x;
    species
    {
        N2 { rotationalTemperature translationalT_N2; }
        N  { }
        O  { }
    }
    electrons
    {
        numberDensity   1e+21;      // [m^-3] or a field name
        temperature     10000;      // [K] or a field name
    }
}

Decomposed runs. The reader uses the case root only. If the case is decomposed and not reconstructed (processor0 holds a later time than the root, or the requested time exists in processor0 only), it stops with a fatal error asking for reconstructPar.

Every cell of the DSMC mesh becomes a profile cell, so the DSMC mesh should be a 1-D row of cells along direction; the reader does not average over the other two directions.

Shock position

shockTubeProfile does not shift or align the profile: \(x\) is the coordinate of the macro file or of the DSMC mesh. The shock front used for the measured quantities (distance behind the shock, nonequilibrium metric) is found by the instrument model of shockTube1D from the measured band profile, or given as a fixed position (shockFront of each camera, Instrument model: reproducing a shock-tube measurement).

Member functions

  • size(): number of cells; x(): positions [m], sorted; sourceInfo(): description for the log;

  • setState(celli, state): fills the number densities and the five temperatures of every species and \(n_e\), \(T_e\) of cell celli into a radiationCellState (Common data classes); the species names, masses and radii are left unchanged;

  • nearestCell(x): index of the cell nearest to position \(x\) (used to match the distribution cells, Transport classes).

Writing a macro file from other data: the tutorial tutorials/shockTube1D/macroFile ships a synthetic profile (constant/profile.csv), and tutorials/shockTube1D/fromDsmcCase reads the same profile from the fields of tutorials/shockTube1D/dsmcCase (shockTube1D: radiance along a 1-D post-shock profile).
