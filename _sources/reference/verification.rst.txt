Verification Record
===================

The present page records the verification of radiationFoam as it is
written in the repository: the commit messages and the specifications in
``docs/``. Every result below is quoted from the commit given in the first
column (short hash of the radiationFoam repository, ``git show <hash>``).
The code was developed in the DSMC_Rovibronic repository and moved here
with its history on 2026-11-16 (commit ``83fd476``); the dated reports
named in the commit messages (``run/RAD/...``) are kept in that
repository.

Verification means comparison with an analytic result, an independent
transcription of the same formulas, or another code solving the same
equations. Comparisons with experiment (EAST) are listed separately at the
end.

How the verification was organised
-----------------------------------

The library was first written as a transcription of the radiation module
of the PICLas code, and every routine was checked against PICLas reference
outputs, to round-off where the same constants were used (phases 1a-2e,
2026-11-14). On 2026-11-14 the replica options were removed by user
decision and only the corrected physics was kept (commit ``9ea3d42``;
``docs/RADIATION_RESTRUCTURE.md`` section 6). From then on, every change
has been gated by md5 identity of the regression outputs, the instrument
test suite and independent Python references. PICLas appears below only as
the past verification reference.
