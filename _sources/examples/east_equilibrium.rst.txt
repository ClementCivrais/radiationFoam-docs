EAST equilibrium columns
========================

Directory: ``tutorials/EAST/equilibrium/``.

Purpose
-------

The first comparison of radiationFoam with experiment, independent of any
gas-kinetic model. Far enough behind the shock, the EAST test gas reaches
thermochemical equilibrium, and its radiance depends only on the equilibrium
state and on the radiation model. Each case of this tutorial is a uniform
column of air at the equilibrium post-shock state of one EAST shot, measured
by the instrument of that shot's camera, and its band radiance is the
quantity that Brandis and Cruden (2017) report as the "equilibrium radiance"
of the shot.

Physics shown
-------------

* All air radiators of the database together: N, O, N\ :sup:`+`,
  O\ :sup:`+` (``atomicLines``, NIST ASD 5.12 levels and lines, Johnston
  2006 Stark widths for N I and O I, none for the ions) and N\ :sub:`2`,
  N\ :sub:`2`\ :sup:`+`, NO, O\ :sub:`2` (``diatomicBands``).
* The continuum (``continuum physical``, :doc:`/theory/continuum`): bound-free
  photoionisation of N and O with N\ :sup:`+`, O\ :sup:`+` as partners
  (tabulated cross sections) and free-free emission on the ions.
* Self-absorption across the 10.16 cm column (:doc:`/theory/transport`).
* The EAST instrument line shape of each shot and camera
  (:doc:`/theory/instrument`): sqrt-Voigt ILS1, Gauss + Lorentz ILS2 or a
  Gaussian, with the half widths of Brandis and Cruden (2017),
  Tables C1-C8; band integrals over the benchmark windows; an "equilibrium"
  spectrum averaged over the column.

The generator: make_cases.py
----------------------------

The directory holds no case: ``make_cases.py`` writes them. Its inputs are

``eq_states.csv``
   The equilibrium post-shock state of 24 EAST shots at 0.2 Torr and 300 K
   fill: shock speed ``U_kms``, ``T2_K``, ``p2_Pa``, density, velocity, total
   number density and the number density [m\ :sup:`-3`] of N\ :sub:`2`,
   O\ :sub:`2`, NO, N, O, N\ :sub:`2`\ :sup:`+`, O\ :sub:`2`\ :sup:`+`,
   NO\ :sup:`+`, N\ :sup:`+`, O\ :sup:`+`, e\ :sup:`-` and Ar. The states are
   full Rankine-Hugoniot jumps to thermochemical equilibrium with the electron
   pressure, computed in the DSMC_Rovibronic repository
   (``run/RAD/EAST/equilibrium/eq_states.py``; method in its
   ``VALIDATION_EQ_REPORT.md``, section 1). For shot 50-29 (10.29 km/s):
   :math:`T_2` = 10 332 K, :math:`p_2` = 30.6 kPa,
   :math:`n_e` = 1.20 :math:`\times 10^{22}` m\ :sup:`-3`.

tables inside the script
   ``ATOMS``, ``MOLS``: species data (mass, radius, database file, ionisation
   energy, Stark exponent 0.33); ``BAND``: the benchmark window and grid
   spacing of each camera (Brandis and Cruden 2017, Figs. 6(a)-14(a));
   ``ILS``: the shots of each camera and their line shape (form, :math:`w_G`,
   :math:`w_L`, :math:`\log_{10} a`); ``CUT``: the ILS cut-off, 10 nm for
   the sqrt-Voigt and 20 nm for the Gauss + Lorentz form (not published);
   ``SPECTRA``: four spectrum cases of shots 50-29 and 57-16 on the full
   camera ranges.

Usage:

.. code-block:: bash

   python3 make_cases.py [variant]     # stark | meinel | full (default full)

writes ``cases_<variant>/<name>/`` and the list ``cases_<variant>/list.txt``.
The variants switch the database content on one step at a time, so that each
change has its own column: ``stark`` (N I / O I Stark widths, the
N\ :sub:`2`\ :sup:`+` Meinel band removed from a copy of ``N2plus.dat``, no
continuum), ``meinel`` (``stark`` plus the full ``N2plus.dat``), ``full``
(``meinel`` plus ``continuum physical``). Fifty cases are written per variant:

* ``spec_<shot>_<camera>`` (4): spectrum cases on the full camera ranges of
  50-29 VUV and UV/Vis and 57-16 VUV and Blue, with
  ``writeSpectra (1)`` and ``writeCoefficients true``;
* ``bench_<shot>_<camera>`` (26): one per shot and benchmark camera;
* ``diag_50-29_<camera>_<group>`` (20): the 50-29 state in every benchmark
  window with all species, then neutral atoms, ions and molecules alone (the
  group cases run without the continuum, which needs every atom with its
  ion).

One case
--------

Every case is a ``shockTube1D`` deck with a 3-cell uniform profile
(:math:`x` = 0, 5 and 10 cm, written to ``constant/profile.csv``) at the
equilibrium state, every temperature equal to :math:`T_2` and
:math:`T_e = T_2`, and one camera ``C``. The window is the camera range of the
shot (the detector: since 2026-11-17 the EAST line shapes of the
``eastLineShape`` type span it and are normalised over it; a Gaussian ILS keeps
the benchmark window widened by ten half widths). Abbreviated deck of
``bench_50-36_UVVis`` (long form):

.. code-block:: cpp

   mode            shockTube1D;
   populationModel boltzmannTemperatures;
   continuum       physical;
   species { N { ... continuumCoeffs { chargeNumber 0; ionSpecies N+;
                   crossSection tabulated; photoionisationFile ".../N_I_photoionisation.dat"; } }
             O { ... }  N+ { ... continuumCoeffs { chargeNumber 1; } }  O+ { ... }
             N2 { ... } N2+ { ... } NO { ... } O2 { ... } }

   shockTube1DCoeffs
   {
       diameter            0.1016;
       windows { W { minWavelength 327.7; maxWavelength 502; nPoints 87151; } }
       bands   { UVVis (339 471); }
       profile { source macroFile; file "<case>/constant/profile.csv"; }
       writeSpectra        none;
       writeCoefficients   false;
       instrument
       {
           C
           {
               window          W;
               spectralResponse { type eastLineShape; lengthUnit nm; form sqrtVoigt;
                                  halfWidthGauss 0.28; halfWidthLorentz 0.07; cutoff 174.3; }
               bandUnit        nm;
               bands           { UVVis (339 471); }
               shockFront      { position 0; band UVVis; upstreamSide low; }
               distanceUnit    cm;
               spectra         { eq { average (1 9); } }
           }
       }
   }

Points to note:

* No ``spatialResponse``: on a uniform column the SRF is the identity.
* ``shockFront { position 0; }``: there is no front in a uniform column, so
  :math:`x_0` is fixed and the distances are simply :math:`x` in cm.
* ``spectra { eq { average (1 9); } }``: the "equilibrium" spectrum is the
  mean over 1-9 cm, i.e. the uniform column.
* Gauss + Lorentz shapes take ``ratio`` :math:`= \min(1, 10^r)` from the
  tabulated :math:`r`; shot 57-37 Vis/NIR prints :math:`r` = 0.47, outside
  the :math:`[0, 1]` range that ``eastLineShape`` enforces, so :math:`a` is
  clipped to 1.
* The infrared Gaussian cameras use ``type gaussian`` with FWHM
  :math:`= 2 w_G`.

How to run
----------

.. code-block:: bash

   cd tutorials/EAST/equilibrium
   ./Allrun                 # full variant, one benchmark case per camera
   ./Allrun meinel          # another variant
   ./Allrun full all        # all 50 cases of the variant
   ./Allclean               # removes cases_* and __pycache__

Without ``all``, ``Allrun`` runs the five cases ``bench_57-6_DeepVUV``,
``bench_57-14_VUV``, ``bench_50-36_UVVis``, ``bench_50-30_VisNIR`` and
``bench_50-59_IR``, each in a few seconds (cell loop 1-2 s and measurement
3-5 s CPU in the logs of the same decks).

Output
------

Per case, in ``postProcessing/radiationFoam/`` (:doc:`/guide/post_processing`):

* ``bands.csv``: raw band radiance per cell [W m\ :sup:`-2` sr\ :sup:`-1`];
* ``profile.csv``: the cell states;
* ``instrument_C_bands.csv``: the measured band radiance
  [W cm\ :sup:`-2` sr\ :sup:`-1`] per cell; on a uniform column every row is
  the equilibrium radiance of the shot;
* ``instrument_C_spectra.csv``: ``lambda_nm`` and the ``eq`` spectrum
  [W cm\ :sup:`-2` sr\ :sup:`-1` µm\ :sup:`-1`];
* ``spec_*`` and the ``all`` diagnostics also write ``spectra_W.bin``,
  ``emission_W.bin``, ``absorption_W.bin`` and ``.info`` for cell 1.

Comparison with EAST
--------------------

The comparison scripts are not part of the tutorial; they are kept with the
EAST data in the DSMC_Rovibronic repository
(``run/RAD/EAST/equilibrium/compare_pass2.py``, digitised benchmark values
and calibrated EAST data cubes in ``run/RAD/EAST/``). They read
``instrument_C_bands.csv`` (one value per case) and
``instrument_C_spectra.csv``, and plot the equilibrium radiance against the
shock speed of each shot. The figures below were produced from the
``cases_full`` decks generated by the same ``make_cases.py`` and
``eq_states.csv`` (VALIDATION_EQ_REPORT.md, section 7: "second pass"). Present
results are red; EAST is black; the grey dashed line is the first pass, run
before the continuum and the N\ :sub:`2`\ :sup:`+` Meinel band were in the
database.

Expected result
---------------

Present / EAST, per window, shock speed rising (VALIDATION_EQ_REPORT.md,
section 7.2):

   :header-rows: 1
   :widths: 25 50 25

   * - Window
     - present / EAST
     - Geometric mean
   * - Vis/NIR 730-890 nm
     - 1.10, 1.02, 1.11, 1.00
     - 1.06
   * - IR 890-1185 nm
     - 0.86, 1.01, 1.11, 0.94, 1.12, 0.85, 0.83
     - 0.95
   * - VUV 170-180 nm
     - 0.90, 1.09, 1.04, 1.14, 1.26, 1.36, 1.34
     - 1.15
   * - Deep VUV 117-153 nm
     - 0.63, 0.66, 0.57, 0.61
     - 0.62
   * - UV/Vis 339-471 nm
     - 0.51, 0.54, 0.56, 0.55, 0.65, 0.82
     - 0.60

The Vis/NIR and IR windows, dominated by N I and O I lines, agree with EAST
within its 30 % calibration uncertainty at every shot. The VUV 170-180 nm
window agrees up to about 10.7 km/s and is 26-36 % high above. The Deep VUV
is 40 % low: its saturated resonance lines radiate from their wings, which
are cut at 100 times the larger of the Lorentz and Doppler widths, and many
lines have no Stark width. The UV/Vis window is 1.2-2 times low: half of its
radiance at 50-29 is the continuum, and the remaining continuum deficit is
the open item of that report.

Since 2026-11-16 the photoionisation cross sections of N I and O I are the
R-matrix values of Nahar and Pradhan (1997) and Nahar (1998) (the O table of
the former data was misaligned as printed): UV/Vis 0.52, 0.57, 0.60, 0.59,
0.71, 0.88 (geometric mean 0.63), Vis/NIR 1.06, IR 0.96, VUV 1.12, Deep VUV
0.62 (geometric means). The attribution of the remaining UV/Vis deficit to
every published candidate (lines without an ASD transition probability, O\
:sup:`-` photodetachment, dissolved levels, electron-neutral free-free) and
to the EAST side is in ``docs/reports/CONTINUUM_UV_20261116.md``.
