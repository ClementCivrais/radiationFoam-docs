EAST shot 50-29 on a dsmcFoam run
=================================

See :doc:`east_validation` for the November 2026 comparison with EAST.

Directory: ``tutorials/EAST/east5029/`` (``README.md``, ``Allrun``,
``Allclean``, ``system/controlDict``, ``system/radiationProperties``).

Purpose
-------

This is the deck the code was written for: the radiance of a nonequilibrium
shock layer computed directly from the state-resolved populations of the gas
kinetics, and measured as EAST measured it. It reads a dsmcFoam simulation of
EAST shot T50-29 (10.29 km/s, 0.2 Torr air, 79 % N\ :sub:`2` / 21 %
O\ :sub:`2`; Brandis and Cruden 2017, Table 1), takes the :math:`(n,v,J)`
level populations sampled by dsmcFoam in every cell, and reproduces the two
benchmark cameras of the shot, VUV and UV/Vis, with their line shapes,
spatial resolution, shock-front definition, nonequilibrium metric and
spectra.

The deck reads the fields and distribution blocks from a completed dsmcFoam
run. The ten-block production comparison, including both camera profiles and
the downloadable radiance tables, is in :doc:`east_validation`.

Physics shown
-------------

* **Populations from the DSMC distribution** (``populationModel
  cellDistribution``, :doc:`/theory/populations`): the level populations of
  every cell are those written by the dsmcFoam function object
  ``dsmcRadiationDistribution``, with no assumption on their shape; each
  distribution cell is matched to the nearest profile cell along the tube,
  which gives :math:`T_\mathrm{trans}`, :math:`n` and the electrons (line
  shapes).
* **Radiators**: N\ :sub:`2` (``diatomicBands``), N and O (``atomicLines``,
  NIST ASD 5.12 ionisation limits, Stark exponent 0.33 of Johnston 2006).
* **The full EAST measurement** (:doc:`/theory/instrument`): sqrt-Voigt ILS,
  composite SRF (optics triangle, camera sqrt-Voigt, gate top hat), front at
  the peak radiance, nonequilibrium metric over :math:`\pm 2` cm, spectra at
  the peak, as metric and as an equilibrium average.

Input expected from dsmcFoam
----------------------------

From ``README.md``:

#. A **reconstructed** dsmcFoam case of the shot (``reconstructPar`` done),
   1-D along :math:`x`, shock frame, free stream entering at low :math:`x`.
   ``profile { source dsmcCase; }`` reads the fields of its latest time:
   ``rhoN_<s>`` [m\ :sup:`-3`], ``translationalT_<s>`` and ``internalT_<s>``
   [K] of N\ :sub:`2`, N and O, and the electron fields ``rhoN_E-`` and
   ``translationalT_E-`` (``dsmcVolFields`` names; check the names of your
   run).
#. The level distributions of every cell, written during the same run by the
   function object ``dsmcRadiationDistribution`` of the plug-in
   ``libdsmcRadiationCoupling`` (DSMC_Rovibronic repository,
   ``src/lagrangian/DSMC/radiationCoupling``; format in
   ``docs/RADIATION_COUPLING_SPEC.md``), in
   ``<case>/postProcessing/dsmcRadiationDistribution/<name>/<time>/`` (the
   index ``cells`` and one file ``cell<k>`` per cell). See
   :doc:`/guide/dsmcfoam_coupling`.

Case files
----------

``system/controlDict`` is the one-step dictionary of every radiationFoam
case (``endTime 0``). ``system/radiationProperties`` starts with a header
that cites every instrument value (Brandis and Cruden 2017, Tables C2, C4,
D3, D4, transcribed in ``run/RAD/EAST/shots.csv`` of the DSMC_Rovibronic
repository) and lists the values that are *not* published (FLAGS, below).
Its main entries:

.. code-block:: text

   mode            shockTube1D;
   populationModel cellDistribution;       // DSMC (n,v,J) populations

   continuum       physical;               // bound-free and free-free of N, O, N+, O+

   species
   {
       N2  { model diatomicBands; ... N2.dat }
       N   { model atomicLines; ... N_I.dat;  continuumCoeffs { ... N_I_photoionisation.dat } }
       O   { model atomicLines; ... O_I.dat;  continuumCoeffs { ... O_I_photoionisation.dat } }
       N+  { model atomicLines; ... N_II.dat; continuumCoeffs { chargeNumber 1; } }
       O+  { model atomicLines; ... O_II.dat; continuumCoeffs { chargeNumber 1; } }
       N2+ { model diatomicBands; ... N2plus.dat }
       NO  { model diatomicBands; ... NO.dat }
   }

   shockTube1DCoeffs
   {
       diameter            0.1016;         // [m], Sec. II p.2

       windows
       {
           VUV     { minWavelength 161.9; maxWavelength 218; nPoints 28051; }
           UVVis   { minWavelength 327.7; maxWavelength 502; nPoints 87151; }
       }

       bands                               // raw (unconvolved) bands [nm]
       {
           VUV_EAST        (162 218);
           UVVis_EAST      (328 477);
       }

       profile
       {
           source      dsmcCase;
           case        "$DSMC_CASE";               // set by Allrun
           time        latestTime;
           direction   x;
           species     { N2 { } N { } O { } N+ { } O+ { } N2+ { } NO { } }
           electrons   { numberDensity rhoN_E-; temperature translationalT_E-; }
       }

       distribution
       {
           directory   "$RADDIST_DIR";             // set by Allrun
           direction   x;
       }

       writeSpectra        none;   // the raw spectra of ~1.3e4 cells are 1e10 values

       instrument { VUV { ... } UVVis { ... } }
   }

``windows``
   Each window is the camera range of 50-29, i.e. the detector (VUV
   161.9-218.0 nm, profile 162-218 nm; UV/Vis 327.7-502.0 nm, profile
   328-477 nm; since 2026-11-17 without margin: the line shape spans the
   detector), at 2 pm spacing.

``profile``, ``distribution``
   The two dsmcFoam inputs; ``$DSMC_CASE`` and ``$RADDIST_DIR`` are set by
   ``Allrun``. With ``cellDistribution`` the cells measured are those of the
   distribution files.

The VUV camera:

.. code-block:: cpp

   VUV
   {
       window          VUV;

       // ILS1, Table C2: wg 0.084 nm, wl 0.0025 nm (HWHM); FWHM 0.242 nm
       spectralResponse
       {
           type            eastLineShape;
           lengthUnit      nm;
           form            sqrtVoigt;
           halfWidthGauss  0.084;
           halfWidthLorentz 0.0025;
           cutoff          56.1;       // the camera width: spans the detector (FLAG: range not published)
       }

       // SRF = f_opt (x) f_cam (x) f_motion, Table D3: d_opt 0.041 cm,
       // camera wg 0.026 cm, wl 0.063 cm, d_gate 0.514 cm
       spatialResponse
       {
           type            composite;
           lengthUnit      cm;
           functions
           {
               optics  { type trapezoid; baseWidth 0.041; topWidth 0; }
               camera  { type eastLineShape; form sqrtVoigt;
                         halfWidthGauss 0.026; halfWidthLorentz 0.063; cutoff 10; }
               motion  { type topHat; width 0.514; }
           }
       }

       bandUnit        nm;
       bands           { VUV_EAST (162 218); }      // Fig. 9(b)

       shockFront      { criterion peakRadiance; band VUV_EAST; upstreamSide low; }

       distanceUnit    cm;
       metricHalfWidth 2;              // Sec. III.B: +/- 2 cm
       spatialBinWidth 0.005;          // 50 um bins (SRF ~0.5 cm)

       spectra
       {
           nonequilibrium  { at peak; }
           metric          { metric 2; }        // Fig. A7(b)
           equilibrium     { average (3 4.5); } // FLAG: range not published
       }
   }

The UV/Vis camera has the same structure with the 50-29 UV/Vis values: ILS
:math:`w_G` = 0.28 nm, :math:`w_L` = 0.070 nm (Table C4, FWHM 0.923 nm);
SRF optics 0.041 cm, camera :math:`w_G` = 0.021 cm, :math:`w_L` = 0.004 cm,
gate 0.257 cm (Table D4); band ``UVVis_EAST (328 477)`` (Fig. 11(a)).

``spatialBinWidth 0.005`` averages the DSMC cells over 50 µm bins before the
measurement: the bins are ten times narrower than the SRF, and the field to
convolve shrinks accordingly (:doc:`/theory/instrument`).

FLAGS: values not published
~~~~~~~~~~~~~~~~~~~~~~~~~~~

The header of the deck lists the instrument values that are provisional:

* **The sqrt-Voigt normalisation range** (``cutoff``) of the ILS and of the
  camera spatial function: Brandis and Cruden (2017) App. C say only that the
  normalisation "is not expressed analytically, and must be done
  numerically". Since 2026-11-17 the ILS spans the detector: the window is
  the camera range, the cut-off its width and every kernel is normalised over
  it (the long-range wings come from the intensified CCD, which spreads only
  the light that falls on it; Brandis et al. 2015, Brandis and Cruden 2017
  Sec. IV.A); the 57-16 VUV floor between the N I multiplets selects it
  (``docs/reports/EAST_VUV_FLOOR_FIX_20261117.md``; the former 10 nm left
  0.14 of it). The spatial cut-off of 10 cm reproduces the SRF tabulated on
  -10..10 cm in the public Test 59 release to 3 % of the peak.
* **The optics width**: Eq. D1 is a triangle of *base* :math:`d_\mathrm{opt}`
  (used here, 0.041 cm); the public Test 57 release defines the same 0.041 cm
  as a *half* width. The factor 2 is negligible against the gate top hat.
* **The x range of the "equilibrium radiance"**: not stated (Sec. III.B);
  3-4.5 cm behind the front is used.

How to run
----------

.. code-block:: bash

   cd tutorials/EAST/east5029
   export DSMC_CASE=/path/to/reconstructed/dsmcFoam/case
   ./Allrun                    # every distribution cell (hours: ~1e4 cells x 1e5 wavelengths)
   STRIDE=10 ./Allrun          # every 10th distribution cell, copied into constant/radDist
   RADDIST_DIR=<dir> ./Allrun  # another distribution block than the latest one
   ./Allclean                  # removes postProcessing, constant and the logs

``Allrun`` stops if ``DSMC_CASE`` is not a directory. Without
``RADDIST_DIR`` it takes the latest time directory holding a ``cells`` file
under ``$DSMC_CASE/postProcessing/dsmcRadiationDistribution/*/``. With
``STRIDE`` :math:`k > 1` it copies every :math:`k`-th distribution cell (and
the comment lines of ``cells``) into ``constant/radDist`` and points
``RADDIST_DIR`` there.

Output
------

In ``postProcessing/radiationFoam/`` (:doc:`/guide/post_processing`):

* ``bands.csv``, ``profile.csv``: the raw (unconvolved) band radiance and the
  cell states;
* ``instrument_VUV_bands.csv``, ``instrument_UVVis_bands.csv``: the measured
  band profile [W cm\ :sup:`-2` sr\ :sup:`-1`] against the distance behind
  the front [cm], with :math:`x_0` and the nonequilibrium metric in the
  header;
* ``instrument_VUV_spectra.csv``, ``instrument_UVVis_spectra.csv``: the
  ``nonequilibrium`` (at the peak), ``metric`` and ``equilibrium`` (mean over
  3-4.5 cm) spectra [W cm\ :sup:`-2` sr\ :sup:`-1` µm\ :sup:`-1`].

The equilibrium spectrum needs a domain extending at least 4.5 cm behind the
front: on a shorter test domain radiationFoam stops at that spectrum with
"x range ... is outside the profile", after writing the other outputs.

Comparison with EAST
--------------------

The measured quantities are in the units and on the axes of Brandis and
Cruden (2017): the band profiles against the VUV (162-218 nm, Fig. 9(b)) and
UV/Vis (328-477 nm, Fig. 11(a)) profiles of 50-29, the metric with the
nonequilibrium metric of the shot, and the three spectra with Figs. A7 (VUV)
and A22 (UV/Vis). Digitised profiles and spectra, the tables of the paper and
a reader of the calibrated EAST data cubes are in ``run/RAD/EAST/`` of the
DSMC_Rovibronic repository (its ``README.md`` lists every source).

.. note::

   The deck radiates every air radiator whose (n,v,J) populations the
   dsmcFoam deck of the shot samples (N, O, N\ :sup:`+`, O\ :sup:`+`,
   N\ :sub:`2`, N\ :sub:`2`\ :sup:`+`, NO), with the bound-free and
   free-free continuum, as the ``full`` variant of :doc:`east_equilibrium`.
   The UV/Vis window (328-477 nm) is dominated by N\ :sub:`2`\ :sup:`+` first
   negative and N\ :sub:`2` second positive (Cruden and Brandis 2020,
   Table 4). O\ :sub:`2` (Schumann-Runge) is left out because the dsmcFoam
   deck samples no O\ :sub:`2` distribution.

   The dsmcFoam deck samples only the *upper* electronic states of the
   molecular systems (N\ :sub:`2` A, B, C; N\ :sub:`2`\ :sup:`+` A, B;
   NO A, B, C). With the default ``missingLevels zero`` the lower states
   (N\ :sub:`2`\ :sup:`+` X, NO X) are empty, so these bands emit but do not
   self-absorb. ``cellDistributionCoeffs { missingLevels boltzmannFill; }``
   fills them at the species :math:`T_{\mathrm{el}}` of the cell
   (:doc:`/theory/populations`).
