Input Reference

The present page lists every keyword that radiationFoam and libradiationFoam read, grouped by dictionary and model. The list was built from the parsers themselves (every get, getOrDefault, readIfPresent, found, lookup, subDict and findDict call in src/radiation and applications), so it documents what the code reads, not an intended interface. “required” in the Default column means that a missing entry stops the run with a FatalIOError.

Unless a row says otherwise, quantities are SI (m, m-3, K, kg, s). The exceptions are the spectral grid and band bounds (nm), the atomic ionisation energy (cm-1) and the lengths of the instrument dictionaries (lengthUnit, bandUnit, distanceUnit).

The physics behind each keyword is explained in the Theory Guide; the classes that read them in Library Classes.

Overview

Everything is read from system/radiationProperties:

radiationProperties
├── mode                          singleCell | shockTube1D
├── populationModel               boltzmannTemperatures | cellDistribution
├── <populationModel>Coeffs       optional
├── continuum                     none | physical          (optional)
├── species
│   └── <s>                       one per radiating species
│       ├── model, mass, radius
│       ├── <model>Coeffs         atomicLinesCoeffs | diatomicBandsCoeffs
│       ├── continuum             optional per-species override
│       └── continuumCoeffs       continuum physical only
├── spectralGrid                  singleCell
├── cellState                     singleCell
└── shockTube1DCoeffs             shockTube1D
    ├── diameter, windows, bands, profile
    ├── distribution              optional (cellDistribution)
    ├── writeSpectra, writeCoefficients, writeDistributions
    └── instrument                optional
        └── <camera>
            ├── window, wavelengthRange, bandUnit, bands
            ├── spectralResponse, spatialResponse   (instrument functions)
            ├── shockFront, distanceUnit, metricHalfWidth, spatialBinWidth
            └── spectra, writeField

Two other inputs are files with their own format: the level-distribution files (Level-distribution file) and the macro file of a 1-D profile (Macro file). The data files of the database (transition files, photoionisation files) are described in Database files and generators.

system/controlDict is the standard OpenFOAM file (see Running radiationFoam); radiationFoam reads no keyword of its own there.

Continuum

The continuum is built by continuumProcesses (continuum/continuumProcesses/continuumProcesses.C). With physical, for every species of model atomicLines:

  • a boundFreePhysical process if continuumCoeffs gives ionSpecies (else none, reported in the log);

  • a freeFreePhysical process if chargeNumber \(\geq 1\).

Species of another model are skipped by the global entry. Theory in Continuum radiation.

Level-distribution file

Read by radiationCellState::readDistribution (common/radiationCellState/radiationCellState.C), for cellState/distributionFile and for every cell<k> file of shockTube1DCoeffs/distribution. It is an OpenFOAM dictionary, the format written by the dsmcFoam function object dsmcRadiationDistribution (Coupling with dsmcFoam):

cell    12;                     // optional, -1 if absent (fill report)
N
{
    levels
    (
        (1)        9.6e20       // atom: one level label of the transition file
        (6 7 8)    3.1e15       // atom: a group of level labels
    );
    g        ( 4 36 );          // optional: DSMC level weight per entry
    coverage complete;          // optional: every carried level is an entry
}
N2
{
    levels
    (
        (X 0 12)   1.2e18       // diatomic: (electronic state, v, J)
        ("B'" 1 3) 4.0e12       // quoted when not a valid word
    );
    coverage ( (X 0 0 98) (X 1 0 97) );   // optional: runs (state v J0 J1) carried
}

One sub-dictionary per species. A species absent from the file has no distribution (fatal for cellDistribution); an empty levels ( ); is a distribution with no populated level.

Mode shockTube1D

transport/derived/shockTube1D/shockTube1D.C: the cells of a 1-D profile, each an independent uniform slab of thickness \(D\) (the tube diameter), with radiance \(I_\lambda=-(j_\lambda/\kappa_\lambda)\,\mathrm{expm1}(-\kappa_\lambda D)\) (\(j_\lambda D\) when \(\kappa_\lambda=0\)). Theory in Radiative transfer.

Each sub-dictionary of spectra is one measured spectrum, a column of instrument_<camera>_spectra.csv [W cm-2 sr-1 µm-1]. Exactly one of:

Entry

Type

Spectrum

instrument
{
    VUV
    {
        window          VUV;
        spectralResponse
        {
            type            eastLineShape;
            lengthUnit      nm;
            form            sqrtVoigt;
            halfWidthGauss  0.084;
            halfWidthLorentz 0.0025;
            cutoff          56.1;       // camera width: the line shape spans the detector
        }
        spatialResponse
        {
            type            composite;
            lengthUnit      cm;
            functions
            {
                optics  { type trapezoid; baseWidth 0.041; topWidth 0; }
                camera  { type eastLineShape; form sqrtVoigt;
                          halfWidthGauss 0.026; halfWidthLorentz 0.063; cutoff 10; }
                motion  { type topHat; width 0.514; }
            }
        }
        bandUnit        nm;
        bands           { VUV_EAST (162 218); }
        shockFront      { criterion peakRadiance; band VUV_EAST; upstreamSide low; }
        distanceUnit    cm;
        metricHalfWidth 2;
        spatialBinWidth 0.005;

            nonequilibrium  { at peak; }
            metric          { metric 2; }
            equilibrium     { average (3 4.5); }
        }
    }
