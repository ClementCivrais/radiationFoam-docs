Spectral quantities and conventions

This page fixes the quantities every other theory page uses: the wavelength grid, the units, the emission and absorption coefficients, the source function and the radiative transfer equation along a ray. It ends with a map from each piece of physics to the library directory that implements it, the place to start reading the code.

All of it lives in one library, libradiationFoam (src/radiation). The application radiationFoam (applications/solvers/radiationFoam) only builds the radiating species, the population model and the continuum, selects a transport mode and runs it.

Wavelength grid

Spectra are computed on a uniform grid of vacuum wavelengths, spectralGrid (src/radiation/common/spectralGrid):

\[\lambda_i = \lambda_{\min} + i\,\Delta\lambda, \qquad i = 0, \dots, N-1,\]
\[\Delta\lambda = \frac{\lambda_{\max} - \lambda_{\min}}{N - 1},\]

where \(\lambda_{\min}\) and \(\lambda_{\max}\) are the entries minWavelength and maxWavelength (given in nm, stored in m) and \(N\) is nPoints. The constructor stops if \(\lambda_{\max} \le \lambda_{\min}\) or \(N < 100\).

spectralGrid
{
    minWavelength   867.9;   // [nm]
    maxWavelength   869.2;   // [nm]
    nPoints         1000;    // [-], >= 100
}

The singleCell mode reads one such grid; shockTube1D reads one per spectral window (sub-dictionaries of windows), see Radiative transfer.

Each grid point stands for a bin. The bin of point \(i\) is \((\lambda_{i-1}, \lambda_i]\) (with \(\lambda_{-1} = \lambda_{\min} - \Delta\lambda\)), and the value a line gives to point \(i\) is the integral of its profile over that bin divided by \(\Delta\lambda\). A line inside the window therefore integrates to exactly one on any grid, however narrow it is (src/radiation/radiators/basic/radiatingSpecies/radiatingSpecies.H; details in Line shapes and broadening).

Wavelengths and wavenumbers

All wavelengths are vacuum wavelengths; no air conversion is made anywhere. Atomic line positions are read in Ångström from the database and stored in metres (\(\times 10^{-10}\)). Molecular line positions are computed as wavenumbers \(\tilde\nu\) in cm-1 from term values and placed at

\[\lambda = \frac{1}{100\,\tilde\nu} \quad [\mathrm{m}], \qquad \tilde\nu\ \text{in cm}^{-1}.\]

Energies in the data files are in cm-1 and are converted to joules by \(E = 100\,h c\,\tilde E\).

Physical constants

The radiators and population models carry their own constants, the exact SI 2019 values (OpenFOAM’s DimensionedConstants hold six digits only): \(k_B = 1.380649\times10^{-23}\) J K-1, \(h = 6.62607015\times10^{-34}\) J s, \(c = 299792458\) m s-1, \(e = 1.602176634\times10^{-19}\) C, and in diatomicBands the CODATA 2018 atomic mass unit \(1.66053906660\times10^{-27}\) kg.

Emission and absorption coefficients

Every radiator adds two spectral fields on the grid (radiatingSpecies::addEmissionAbsorption):

Quantity

Units

Meaning

\(j_\lambda\)

W m-3 sr-1 m-1

spontaneous emission coefficient: power emitted per unit volume, solid angle and wavelength

\(\kappa_\lambda\)

m-1

absorption coefficient, net of stimulated emission

\(I_\lambda\)

W m-2 sr-1 m-1

spectral radiance (specific intensity)

\(\int I_\lambda\,d\lambda\)

W m-2 sr-1

band-integrated radiance (bands.csv of shockTube1D)

\(4\pi\int j_\lambda\,d\lambda\)

W m-3

emitted power per unit volume (profile.csv of shockTube1D)

Both coefficients are per unit wavelength. The \(4\pi\) appears only in volumetric totals. The coefficients of the species and of the continuum processes are summed:

\[j_\lambda = \sum_s j_{\lambda,s} + j_\lambda^{\mathrm{cont}}, \qquad \kappa_\lambda = \sum_s \kappa_{\lambda,s} + \kappa_\lambda^{\mathrm{cont}}.\]

A bound-bound line \(u \to l\) contributes a line-integrated coefficient times a normalised profile \(\phi_\lambda\) (\(\int\phi_\lambda\,d\lambda = 1\), units m-1):

\[j_\lambda = \epsilon_{ul}\,\phi_\lambda(\lambda - \lambda_0), \qquad \kappa_\lambda = k_{ul}\,\phi_\lambda(\lambda - \lambda_0),\]

with

\[\epsilon_{ul} = \frac{h c}{4\pi\lambda_0}\,n_u A_{ul} \quad [\mathrm{W\,m^{-3}\,sr^{-1}}],\]
\[k_{ul} = \frac{\lambda_0^4}{8\pi c}\,A_{ul}\,g_u \left(\frac{n_l}{g_l} - \frac{n_u}{g_u}\right) \quad [\mathrm{m^{-1}\,m}].\]

Here \(n_u, n_l\) are the level number densities (m-3), \(g_u, g_l\) their statistical weights and \(A_{ul}\) the Einstein coefficient for spontaneous emission (s-1). The second term of \(k_{ul}\) is stimulated emission. When the pair of levels is inverted (\(n_u/g_u > n_l/g_l\)), \(k_{ul} < 0\): the line is a gain, and the code keeps the negative value. The atomic forms are in Atomic bound-bound lines, the molecular ones (written with band strengths and Hoenl-London factors) in Diatomic band systems, line by line.

Source function

The source function is the ratio

\[S_\lambda = \frac{j_\lambda}{\kappa_\lambda}.\]

For a single line, the two expressions above give

\[S_\lambda = \frac{2 h c^2}{\lambda^5}\, \frac{1}{\dfrac{n_l\,g_u}{n_u\,g_l} - 1},\]

which depends on the populations only through the ratio of the two levels. When the two levels are in Boltzmann equilibrium at a temperature \(T\), \(n_l g_u/(n_u g_l) = \exp(hc/\lambda k_B T)\) and \(S_\lambda\) becomes the Planck function

\[B_\lambda(T) = \frac{2 h c^2}{\lambda^5}\, \frac{1}{\exp\!\left(\dfrac{hc}{\lambda k_B T}\right) - 1},\]

i.e. Kirchhoff’s law \(j_\lambda = \kappa_\lambda B_\lambda\). Out of equilibrium the code never assumes this relation: \(j_\lambda\) and \(\kappa_\lambda\) are computed separately from the upper and lower populations of each line, whatever their origin (Level populations). The source function is then the generalised Kirchhoff form above, line by line.

Radiative transfer equation

Along a ray of path length \(s\) the radiance obeys

\[\frac{dI_\lambda}{ds} = j_\lambda(s) - \kappa_\lambda(s)\,I_\lambda(s).\]

Scattering is not modelled. With the optical depth \(\tau_\lambda(s) = \int_0^s \kappa_\lambda\,ds'\), the formal solution for a ray entering with \(I_\lambda(0)\) is

\[I_\lambda(s) = I_\lambda(0)\,e^{-\tau_\lambda(s)} + \int_0^s j_\lambda(s')\, e^{-[\tau_\lambda(s) - \tau_\lambda(s')]}\,ds'.\]

For a uniform slab of thickness \(D\) and no incoming radiance, this reduces to

\[I_\lambda = S_\lambda\left(1 - e^{-\kappa_\lambda D}\right) = -\frac{j_\lambda}{\kappa_\lambda}\, \mathrm{expm1}(-\kappa_\lambda D),\]

with the optically thin limit \(I_\lambda = j_\lambda D\) when \(\kappa_\lambda D \ll 1\). This is the form the shockTube1D mode evaluates for each cell of a shock-tube profile (it uses expm1 so the thin limit is exact to round-off, and it holds for either sign of \(\kappa_\lambda\)); see Radiative transfer. The instrument model that turns this radiance into what a spectrometer records is in Instrument model: reproducing a shock-tube measurement.

The data flow of one run is: the species are built once (levels and line lists, radiators/); for every cell, the population model gives the number density of every level (populations/); each radiator adds its \(j_\lambda\), \(\kappa_\lambda\) with the line profiles (lineShapes/), the continuum adds its own (continuum/); the transport mode turns the coefficients into radiance (transport/) and, optionally, into a simulated measurement (instrument/).
